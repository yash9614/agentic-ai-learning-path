# sunnysavita10/Full-Stack-GenAI-Bootcamp-1.0 — Analysis

Full-stack bootcamp covering foundations → Transformers → fine-tuning → RAG → Agentic AI / LangGraph → MCP / guardrails / evaluation.

**Repo:** https://github.com/sunnysavita10/Full-Stack-GenAI-Bootcamp-1.0

## Structure Highlights

- **Assignments:** Encoding, Transformer from scratch, LLM exploration, fine-tuning, RAG/MM-RAG, memory-augmented RAG.
- **Class progression (Mar–Nov 2026):**
  - Foundations & embeddings (Class 1–8)
  - Transformers deep dive (Class 9–15)
  - LLM APIs & fine-tuning (Class 16–28: Unsloth, LoRA/QLoRA, RLHF/DPO, multimodal)
  - RAG pipeline (Class 29–39: parsing, FAISS, Chroma/Pinecone/Qdrant, chunking, retrievers, MM-RAG project)
  - Agentic AI & LangGraph (Class 40–50: intro, tools, Pydantic, memory, HITL, subgraphs, multi-agent)
  - Advanced (Class 51–59: LangChain recap, other frameworks, MCP + A2A, guardrails/security, evaluation + DeepEval)
- **Extra folders:** `GenAI-Interview-Questions`, `HITL`, `deep_agentic_system`, `MCP_Guide.pdf`.
