# Interview Questions — Agentic AI

Practice these out loud. Draw the graph when possible.

## Foundational
1. Difference between Generative AI and Agentic AI?
2. What is an agent? Core components?
3. Explain the ReAct pattern.
4. Why use LangGraph?

## LangGraph
5. What is a StateGraph?
6. How do conditional edges work?
7. How do reducers work when parallel nodes write the same field?
8. Subgraph as a node vs invoke — difference?
9. What is `Command`? Difference from a normal edge?
10. How does `Send` enable map-reduce?

## Tools & RAG
11. How does tool calling work?
12. Agentic RAG vs standard RAG?
13. Corrective RAG (CRAG) flow?
14. Name three RAGAS metrics and what they measure.
15. How do you prevent infinite agent loops?

## Multi-Agent & Production
16. Supervisor vs handoffs — when to use each?
17. Human-in-the-loop: when and how (including parallel interrupts)?
18. Short-term vs long-term memory isolation?
19. What is MCP and why use it?
20. How do you add observability and control cost/latency?

## Advanced
21. Hybrid search (BM25 + dense + RRF) vs pure vector?
22. Parent-child chunking — when does it help?
23. GraphRAG multi-hop vs standard vector RAG?
24. LoRA/QLoRA vs full fine-tuning trade-offs?
